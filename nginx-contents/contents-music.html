Music Streaming — music.tikhonnnnn.com

← back to all services

Music streaming is powered by Navidrome, a Subsonic-compatible music server. To use the service you need the login and password provided to you. The same credentials work in the web UI and in any Subsonic-compatible client app.

Server address for client apps: https://music.tikhonnnnn.com

Usage

iOS — Arpeggi

  1. Install Arpeggi from the App Store.
  2. Add a new server: enter https://music.tikhonnnnn.com as the server address.
  3. Sign in with your provided login and password.

Linux / Windows desktop — Feishin

  1. Download Feishin for your platform.
  2. Add a server: choose Navidrome as the server type and enter https://music.tikhonnnnn.com.
  3. Sign in with your provided login and password.

Web — Navidrome UI

  1. Open music.tikhonnnnn.com in your browser.
  2. Sign in with your provided login and password.
